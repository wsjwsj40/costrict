# DiCode Codex MVP

Independent VS Code extension using the unmodified `codex app-server` as its local agent. The existing DiCode login and model list endpoints supply credentials and model IDs. The selected model runs through the standalone `dicode-codex-bridge` Responses endpoint.

The extension automatically downloads the platform-specific unmodified Codex CLI from the DiCode portal on first activation. The installer verifies the archive, waits for extraction handles to close, and can finish by copying the package if Windows blocks the final directory rename. The JSON-RPC handshake and ephemeral thread creation were checked against `codex-cli 0.164.0`. Set `dicodeCodex.serverUrl` to the DiCode APISIX entry. Set `dicodeCodex.codexPath` only to override automatic installation with an existing executable. DiCode's system instructions are supplied through Codex's `model_instructions_file` configuration; the CLI binary is unchanged.

The sidebar now renders app-server Thread, Turn and Item events. It includes streaming Markdown with syntax highlighted code blocks, command output, file changes with inline and native editor Diff, plan updates, reasoning summaries, tool activity and approval requests. The latest 20 turns are cached in VS Code global state for reopening the view; long command outputs are truncated in that cache. Run `npm ci && npm run build && npm test`, then `npx vsce package --no-dependencies`, or launch VS Code's Extension Development Host with this folder as the extension path. The bundled `media/bundle.js` is included in the VSIX, so the webview works without a CDN.

This MVP supports login, model selection, a single persisted thread, streaming replies, command/file approvals, stopping a turn, and a new thread. It requires an open workspace. The old Roo-based extension is not part of this package.
