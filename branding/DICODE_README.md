# Dicode

Dicode is an enterprise AI development assistant that provides agent workflows, code review, code completion, and software engineering utilities directly in Visual Studio Code.

## Main capabilities

- AI-assisted software development workflows
- Local interactive code review and security review
- Intelligent code completion
- Context-aware code explanation and modification
- Configurable enterprise model and service endpoints

For deployment, access, and support information, contact your internal Dicode administrator.
